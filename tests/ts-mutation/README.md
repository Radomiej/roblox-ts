# TypeScript compiler mutation tests

`npm run test:ts:mutation` runs Stryker against the TypeScript-to-Luau compiler. The Jest suite imports the compiler's TypeScript source through the same `Project`, `Shared`, and `TSTransformer` aliases used by the regular compiler tests. It compiles targeted TypeScript fixtures with `createProjectData`, `createProjectProgram`, `createPathTranslator`, and `compileFiles`, builds the generated Luau with Rojo, then executes the built place with Lune.

The generator fixture covers bare `yield`, input forwarding, delegated values and completion values, discarded delegation results, retaining an iterator's original `next` function if the source iterator is later modified, and delegated cancellation. Break and explicit return cases verify nested `finally` order, return-value forwarding, and that custom iterator return methods receive their iterator. A metatable-backed iterator verifies discarded completion values do not trigger observable `.value` reads. The evaluation fixture covers ordinary and macro-lowered call argument order, optional call short-circuiting, nullish and logical assignment laziness, compound indexed assignment, destructuring order and defaults, conditional branches, switch cases, short-circuit logic, computed object keys with spreads, and dynamic string indexing. The `createProjectData` cases cover package discovery and invalid metadata, include and node module defaults, explicit paths, and automatic Rojo selection with ambiguity warnings.

`stryker.ts.config.mjs` mutates `transformYieldExpression.ts` and `createProjectData.ts`; `stryker.prereqs.config.mjs` mutates the evaluation planner at `src/TSTransformer/util/evaluation/plan.ts`. Mutations are handled in-process by Jest, so the compiler code loaded from `src` remains subject to mutation.

The latest TypeScript runtime/project run has 81 mutants: 74 killed, 6 survived, and 1 without coverage. The six survivors in `transformYieldExpression.ts` change temporary variable names. The no-coverage mutation changes the fallback string used when a package has no name; it still classifies as non-package because the fallback does not match the package-name pattern. Its reports are written to `reports/mutation-ts/`.

The latest planner-only run found 101 mutants: 57 killed, 42 survived, and 2 without coverage. It completed with no timeouts or errors. The remaining survivors span primitive/reference slot handling, event/use tracking, capture analysis, and substitution; they are unresolved and should not be treated as equivalent without further evidence. The no-coverage cases are in the capture branch for operands with no expansion uses. Review `reports/mutation-prereqs/mutation.json` for the full mutant list.
